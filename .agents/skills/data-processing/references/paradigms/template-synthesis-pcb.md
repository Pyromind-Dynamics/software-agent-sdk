# PCB 配对参考模板案例

## 材料与异常的来源

- xxx.bmp：实拍，提供可信区域的铜色/底色及标注区域的缺陷像素。
- xxx_cam.bmp：正常结构 GT。保留其结构，将金黑色替换为实拍铜色/底色，
  得到无原缺陷的正常底图；不把有异常的实拍图作为正常底图。
- 标注框/掩码：限定异常证据范围。0..1000 坐标先转换；配准后同步映射。

默认使用同一样本的配对 GT。两张图色调不同，原始 RGB 相减会把正常材料也
判成异常；结构提取使用材料掩码，外观提取使用完成色调转换的参考。

## 提取与放置

真实样本/GT/标注 → 配准 → 局部缺陷提取 → GT 实拍色调重绘 →
合适位置变形 → 结构校验 → 注入 → 同步翻转/旋转 → 高通 diff 与 bbox →
模板/合成复核。

GT 正常铜区的最大连通块只适合统计材料，不能充当缺陷模板。模板应展示
实拍框内异常、提取掩码和排除的正常结构。孔、线路、大片正常铜不能随模板搬走。
所有异常区域及配准不一致区域都排除在正常材质采样范围之外。

| 业务形态 | 提取证据 | 放置/检查依据 |
|---|---|---|
| 多铜、少铜、毛刺、缺口 | 标注内材料结构差异 | 对应材料一侧的边缘，检查连通性及业务尺寸 |
| 开路、短路 | 标注内断开/桥接结构 | 目标线路关系；少铜增加连通块、多铜减少连通块是检查依据 |
| 铜渣、针孔 | 孤立残留或铜内缺损 | 分别位于背景内部、铜内部，与边界保持距离 |
| 膜渣、颗粒、氧化等 | 标注内局部外观异常或已复核掩码 | 按业务定义选择所在材料，保留异常纹理，检查额外异常 |

category 和生成机制分开：某数据将“膜渣”标成“多铜”，不意味着应凭空添加
正常铜块。读取标注备注和视觉证据选机制；无法区分就待复核，不擅自改标签。
GT 分割颜色、实拍材料阈值、配准范围、面积/边界/裁剪上限从当前样例确定，
不硬编码进通用模块。

铜/基材名称需由数据定义或可信参考支持，金黑、明暗及配准得分不决定其含义。
默认保持源缺陷在正常结构上的材料占比与边界关系，使用通用上下文检查；
跨材料或改变连接关系须有独立业务依据，不能仅凭类别名推导允许区。

位置从满足结构关系的候选区中选，再验证完整变形模板；大幅裁剪会改变缺陷，
应拒绝并换位置。只检查“与原铜区不重叠”不能排除短路，须比较注入后的结构。
多铜与铜渣也不能合并为同一条位置规则。

## diff 与复核

默认采用 defect 灰度减自身高斯平滑的有符号残差，显示图为残差幅度；
这是局部纹理响应，正常边缘也会高亮，不是与 GT 的差分，也不是缺陷真值。
参数与 signed 数据均保留；其他方向差分单独实现和命名。

复核图为：合成图上的细线框 | 重绘正常参考 | 高通图；另展示原 GT 到实拍
色调的转换，以及模板源图/GT/提取像素/掩码。框画在合成图上，不给正常图
填蓝色矩形。使用 [模板合成接口](template-synthesis.md) 的固定托管复核入口。
小样逐份检查模板与合成，全量按已确认计划分层抽检；模型失败、unknown、
未抽检如实保留，不以颜色均值或程序检查代替视觉判断。
