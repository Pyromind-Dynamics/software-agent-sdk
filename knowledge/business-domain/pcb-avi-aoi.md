# PCB 裸板 AVI/AOI 领域参考

用于理解 PCB 裸板内外层线路及板面检测的数据、标签和验收诉求，供数据清洗、
分布分析、合成和人工标注共用；不覆盖 PCBA 元件与焊点检测。以下整理自业务
会议经验，不替代当前产品、工序和客户的验收标准，也不规定处理流程。

## 数据与判定的含义

理解数据时关注工序与内外层、成像条件与尺度、参考图来源、标签来源及判定单位
（缺陷点、裁剪图、整板）。局部报警样本的分布不能直接代表整板质量分布。

| 数据角色 | 解读边界 |
|---|---|
| 实拍图 | 提供外观证据；曝光、模糊、遮挡和裁剪会限制可判定范围 |
| 设计图或正常参考 | 提供预期结构；需确认来源、版本、配准和材料含义，颜色未必与实拍一致 |
| 差分或增强图 | 突出变化或纹理；需确认生成方式，正常边缘和错位也可能响应 |
| 设备报警、模型预测 | 候选异常及算法判断，不等同于人工确认的真缺陷 |
| 人工复判 | 依赖当时采用的验收口径；需区分外观类别与放行、拦截结果 |

`gt`、`diff`、`defect` 等文件名不能单独证明图像角色或标签真值。
保留原始标签，类别映射需依据数据说明与样例；多铜/少铜可以是上位类别，
不能与其子类重复计数，也不因参考体系有八类就强制重分类。

## 线路结构缺陷参考

“多铜/少铜”描述相对预期结构的材料增减，具体类别还取决于位置和连接关系。
以下八类是会议采用的参考体系，是否超出允许范围仍由当前验收要求决定。

| 类别 | 材料变化 | 主要结构特征 |
|---|---|---|
| 短路 | 多铜 | 本应分离的线路或铜区被异常桥接 |
| 断路（开路） | 少铜 | 本应连续的线路发生断裂 |
| 毛刺 | 多铜 | 线路或铜区边缘出现多余凸起，关注与邻近结构的间距及连接 |
| 缺口 | 少铜 | 线路或铜区边缘局部缺失，关注剩余宽度及连续性 |
| 铜渣 | 多铜 | 非铜区域出现孤立残留铜点，需与附着异物区分 |
| 针孔 | 少铜 | 线路或焊盘等铜区内部出现局部孔洞，需排除设计本有的开孔 |
| 线宽超标（线宽） | 多铜 | 相对设计或合格参考过宽，不等同于任意边缘凸起 |
| 线宽不足（线细） | 少铜 | 相对设计或合格参考过窄，尚需区分局部缺口与断路 |

断路、短路关注连接关系；毛刺、缺口关注边缘；铜渣、针孔关注所在材料及孤立性。
像素宽度只有结合分辨率、缩放和参考线宽才有可迁移的意义。

## 外观因素与证据

铜色、基材暴露、形态及参考结构应相互印证。会议中的红黄色铜面、过曝白色、
灰白或黑色异物是特定成像条件下的线索，不能作为跨设备通用的单条件分类器。
缺口、针孔处的颜色可与同图可信基材区域比较；不预设所有基材均为 PP 或颜色相同。

| 现象 | 判别与处置边界 |
|---|---|
| 氧化 | 表面变色与铜结构缺失分开描述；是否允许及严重度依据当前标准，不一概当作假点 |
| 垃圾/异物 | 灰尘、毛发、残膜等可能遮挡结构；颜色、细丝形态是线索，异物也不自动等于可放行 |
| 错位/模糊 | 可造成伪差异或证据不足；需结合配准及原图，不能由此排除同时存在的真缺陷 |
| 蚀刻圆角 | 会议将部分圆滑拐角视为工艺允许现象；需结合参考与公差，不能推广为所有圆角均合格 |
| 过曝/扫描黑边 | 属于成像或裁剪因素，可导致不可判区域；保守拦截不等于确认存在铜结构缺陷 |

观察到的现象、缺陷类别、严重度与业务处置是不同维度。“假点”应按当前任务
理解为复判后可过滤的设备报警，而非所有氧化、异物或图像异常的固定别名。
证据不足时保留不确定性；业务要求拦截的样本不能仅因此变成已确认真缺陷训练标签。

## 位置与验收诉求

会议强调信号线缺口的电气影响与大铜皮局部缺失的处置可能不同。理解此类要求
需结合线路用途、设计约束和客户验收标准；不能从局部图像推断信号、电源或地，
也不能仅凭铜区面积大就忽略异常。用户要求减少复判量时，应同时识别其漏检约束。

“过假率”需明确分子、分母、统计单位、评估样本范围和内外层口径。例如，
“过滤掉的已确认假点 / 全部已确认假点”与“过滤报警数 / 全部报警数”不是同一指标；
不能将放行中的真缺陷计为成功过滤。未知口径不自行补齐，80%/70% 目标也不能单独
说明漏检是否可接受。

## 会议现场约定（非跨产线默认规则）

保留这些约定用于解释该现场的数据与诉求；其他数据源仅在适用条件得到确认后采用。

| 会议经验或约定 | 适用边界 |
|---|---|
| 线细通常比标准线宽窄 7–10 像素 | 依赖该现场图像尺度与标准线宽，不作为通用阈值 |
| 氧化按轻微/中度/重度分级，归入假点讨论 | 原记录未给出分级阈值及各级放行边界，不自行补定 |
| 红黄色或过曝白色倾向铜缺陷；灰白、黑色或近基材色倾向异物 | 仅为现场颜色经验，结合材料、结构与曝光条件使用 |
| 细丝状异物无论颜色均归垃圾假点 | 记录该现场标注约定，不以细丝形态直接决定其他产线的放行 |
| 现场通过过曝弱化氧化点，难分辨时优先按真缺陷处理 | 保留其保守拦截意图，另行保留证据不足的事实，不能确认具体缺陷类别 |
| 扫描截取的一侧黑边约占 1%–2%，统一归真缺陷、不特殊处理 | 原记录未明确比例的统计口径；属于现场处置或标签约定，不证明黑边是实体缺陷 |
| 内层过假率目标 80%，外层 70% | 现场目标，不是行业统一标准；采用前需明确指标口径及漏检约束 |
| 氧化、垃圾与真缺陷难区分时“宁误杀不放过” | 表示风险偏好与拦截策略，不凭此断言存在少铜或其他实体缺陷 |
| 信号线缺口必须报出，大铜皮缺失不影响电性能时可酌情忽略 | 需有用途及验收依据，不能仅凭裁剪图或面积作结论 |
