# Anything to String 节点

![alt text](/imgs/AnythingToString/AnythingToString.png)  

## 1.1 功能概述

任意类型转字符串节点：将任何类型的输入转换为字符串输出
这是一个通用的转换节点，用于将 MODEL、STRING 等类型转换为 STRING

## 1.2 输入类型

| 参数 | 数据类型 | 必填 | 描述 |
|------|---------|------|------|
| anything | * | 是 | 任意类型。默认值：""（空字符串） |
## 1.3 输出类型

| 参数 | 数据类型 | 描述 |
|------|---------|------|
| string | STRING | 输入值的字符串表示形式 |
