# Load Model 节点

![alt text](/imgs/LoadModel/LoadModel.png)

## 1.1 功能概述

加载基础模型用于 RL 训练。该节点从指定路径加载预训练模型，并将模型引用传递给下游节点（如训练、推理等）。

## 1.2 输入类型

| 参数 | 数据类型 | 必填 | 描述 |
|------|---------|------|------|
| model_path | STRING | 是 | 模型路径，指向预训练模型所在的目录或文件。默认值：`path/to/model` |

## 1.3 输出类型

| 参数 | 数据类型 | 描述 |
|------|---------|------|
| model | STRING | 加载的模型引用，供下游节点使用 |
