# String to Anything 节点

![alt text](/imgs/StringToAnything/StringToAnything.png)  

## 1.1 功能概述


将字符串输入转换为任意输出类型。


## 1.2 输入类型

| 参数 | 数据类型 | 必填 | 描述 |
|------|---------|------|------|
| input_string | STRING | 是 | 字符串。默认值：- |
## 1.3 输出类型

| 参数 | 数据类型 | 描述 |
|------|---------|------|
| anything | * | 任意类型 |
