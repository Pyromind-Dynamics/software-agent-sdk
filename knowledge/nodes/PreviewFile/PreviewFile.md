# File Preview 节点

![alt text](/imgs/PreviewFile/PreviewFile.png)

## 1.1 功能概述

输入存储路径并预览文件。支持的格式包括图片和 TXT 文件。

## 1.2 输入类型

| 参数 | 数据类型 | 必填 | 描述 |
|------|---------|------|------|
| file_path | STRING | 是 | 要预览的文件存储路径 |

## 1.3 输出类型

| 参数 | 数据类型 | 描述 |
|------|---------|------|
| file_path | STRING | 已预览文件的存储路径 |
