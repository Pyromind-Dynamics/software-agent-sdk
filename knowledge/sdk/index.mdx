轻量级 Python SDK，用于调用 [PyroMind AI](https://pyromind.ai/) 平台 API — 管理训练工作流、Jupyter 实例、推理任务、EchoMind 等。

本索引以工程锁定的 `pyromind-sdk==0.1.17` 为准。先选择任务，再读取对应页面，
无需一次加载全部 API 参考。

## Agent 平台操作

- [Agent 操作索引](agent-operations.mdx) — 按操作查 SDK 方法、准备函数和使用示例
- [CUSTOM 沙箱](sandboxes.mdx) — 创建、等待就绪、文件读写、命令退出码与释放资源

会话中使用 terminal 和 `"$PYROMIND_SDK_PYTHON"` 运行 SDK 脚本，身份和集群由会话提供。
工作流的校验、提交与结果处理见[执行参考](../../.agents/skills/workflow-execution/references/sdk-execution.md)。
