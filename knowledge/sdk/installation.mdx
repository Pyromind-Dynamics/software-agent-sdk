## 通过 PyPI 安装

```bash
pip install pyromind-sdk==0.1.17
```

本工程锁定 `0.1.17`，该版本包元数据声明需要 Python >= 3.8。

## 初始化客户端

```python
import os

from pyromind_sdk import PyroMindAPIClient

with PyroMindAPIClient(
    api_key=os.environ["PYROMIND_API_KEY"],
    cluster=os.environ["PYROMIND_CLUSTER"],
) as client:
    node_info = client.studio.get_node_info()
    print(node_info)
```

先在独立 SDK 脚本环境配置 API Key 和目标集群；示例仅读取节点定义。
Agent terminal 尚未自动获得平台会话 SDK 上下文，不能据此绕过现有 Skill、Tool 或 Runtime 提交流程。
会话内的执行边界见 [Agent 操作索引](agent-operations.mdx)。

Agent 服务会把前端请求的 `X-Cluster` 显式传给 SDK，缺失时使用 `us-west-1`。
下表是直接调用上游 SDK 时的参数默认值。

## 客户端参数

| 参数 | 必填 | 类型 | 默认值 | 说明 |
|------|------|------|--------|------|
| `api_key` | 是* | `str` | `PYROMIND_API_KEY` 环境变量 | API 认证的 Bearer Token |
| `base_url` | 否 | `str` | `PYROMIND_BASE_URL` 环境变量或平台默认地址 | 平台 API 地址 |
| `cluster` | 否 | `str` | `PYROMIND_CLUSTER` 环境变量或 `"us-west-2"` | 目标集群（`X-Cluster` 请求头） |
| `timeout` | 否 | `int` | `30` | 请求超时时间（秒） |
| `max_retries` | 否 | `int` | `3` | 失败请求的最大重试次数 |

\* `api_key` 可作为参数传入，也可通过 `PYROMIND_API_KEY` 环境变量提供。

## 环境变量

| 变量 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| `PYROMIND_API_KEY` | 是 | — | API Bearer Token |
| `PYROMIND_BASE_URL` | 否 | `https://api-portal.pyromind.ai/api/v1` | 平台 API 地址 |
| `PYROMIND_CLUSTER` | 否 | `us-west-2` | 目标集群标识 |
| `PYROMIND_STORAGE_ENDPOINT` | 否 | `https://storage.pyromind.ai` | 存储端点 URL |
| `PYROMIND_STORAGE_SECRET_KEY` | 否 | — | 存储 Secret Key |
| `PYROMIND_STORAGE_BUCKET` | 否 | — | 默认存储桶名称 |
